# Первое сообщение новому ИИ

Скопируйте текст ниже в начало нового сеанса с ИИ, работающим с этим репозиторием:

> Ты помогаешь продолжать официальный сайт филиала школы Muhammad al-Xorazmiy в Фергане. Сначала прочитай `Progress.md`, `Project-Structure.md`, `Design.md`, `Development-Guide.md` и `API-Reference.md`, затем изучи только те исходные файлы, которые относятся к моей задаче.
>
> Это JavaScript-проект: React + Vite + Tailwind CSS на клиенте и Express API на сервере. Данные сохраняются в `server/data.json`, изображения — в `public/assets/`. Интерфейс сайта сейчас на узбекском; документацию со мной веди по-русски. Перепроверяй маршруты в `src/App.jsx`, а реальные npm-команды — в `package.json`.
>
> Перед правками проверь `git status` и не затирай чужие изменения. Делай небольшие изменения строго по задаче, не переписывай приложение без необходимости. Не включай в ответы, логи, коммиты и документы пароли, токены, содержимое `server/data.json` или другие персональные/секретные данные. Перед изменением данных делай резервную копию. Сверяй стили с `Design.md`.
>
> В проекте есть расхождения, которые нельзя принимать за рабочую конфигурацию: `README.md` может описывать устаревшие функции/доступ; Compose содержит сценарий Django/PostgreSQL, не совпадающий с сервером React/Express и JSON; маршруты некоторых существующих файлов страниц перенаправляются; условие отображения оболочки админки следует проверить. Не меняй эти вещи, пока они не относятся к моей задаче или я явно не попрошу.
>
> После изменений запусти подходящую проверку. Для фронтенда доступна `npm run build`; отдельных скриптов тестов и линтинга в `package.json` пока нет. В конце кратко сообщи, что изменено, какие проверки прошли и что осталось неподтверждённым. Если задачу можно выполнить безопасно без уточнения, действуй самостоятельно; если есть несколько существенно разных вариантов или риск потери данных, сначала спроси меня по-русски.

## Порядок знакомства с проектом

1. Проверить `git status`, прочитать этот файл и [`Progress.md`](./Progress.md).
2. Посмотреть карту разделов в [`Project-Structure.md`](./Project-Structure.md).
3. Для UI свериться с [`Design.md`](./Design.md), для API — с [`API-Reference.md`](./API-Reference.md).
4. Перед запуском/деплоем прочитать [`Development-Guide.md`](./Development-Guide.md); не использовать Compose или доступы из старого README как заведомо верные.
5. Найти соответствующий компонент или страницу в `src/`, затем проследить вызовы API в `server/`, если задача затрагивает сохранённые данные.

## Важное для владельца проекта

Вы можете описывать желаемый результат обычными словами — знание JavaScript не требуется. Попросите ИИ объяснить изменения простым русским языком, указать затронутые файлы и дать точные команды для проверки. Не отправляйте в чаты или ИИ пароли, рабочие токены и необработанный файл данных.
