# Разработка и запуск

## Технологии

- JavaScript (без TypeScript), React 19 и React Router.
- Vite 8 — локальный сервер разработки и сборка фронтенда.
- Tailwind CSS 3, PostCSS и Autoprefixer — стили.
- Express 5 — сервер и JSON API.
- `bcryptjs` и `jsonwebtoken` — компоненты административной аутентификации.
- Данные сайта хранятся в `server/data.json`; изображения — в `public/assets/`.

Версии пакетов и скрипты указаны в [`package.json`](./package.json); точные версии для установки зафиксированы в `package-lock.json`.

## Локальная разработка

Требуется установленный Node.js и npm.

```bash
npm ci
npm run dev
```

`npm run dev` запускает Express и Vite параллельно:

- сайт разработки: `http://localhost:5173`;
- API: `http://localhost:5000`;
- Vite перенаправляет запросы `/api` на Express — см. [`vite.config.mjs`](./vite.config.mjs).

## Production-сборка и запуск

```bash
npm ci
npm run build
npm start
```

Vite создаёт `dist/`, затем Express раздаёт собранный SPA и API. По умолчанию Express слушает порт `5000`; порт можно переопределить переменной `PORT`. При изменении фронтенда production-сборку нужно выполнить заново.

## Где находятся данные

[`server/db.js`](./server/db.js) читает и синхронно перезаписывает [`server/data.json`](./server/data.json). Это файловое JSON-хранилище, а не PostgreSQL. Загруженные изображения сохраняются в `public/assets/uploads/` и отдаются через `/assets/`. Перед ручным изменением данных сделать резервную копию; не перезаписывать файл из старой копии поверх более новых изменений.

## Текущие ограничения и проверка перед публикацией

- Отдельных npm-скриптов для тестов и линтинга сейчас нет. Минимальная техническая проверка фронтенда — `npm run build`.
- Не считать Docker-конфигурацию готовой к запуску: Compose ссылается на Django-команды/файлы, которые не входят в этот проект, хотя приложение написано на React и Express. Compose также поднимает PostgreSQL, но `server/db.js` его не использует.
- Порт, объявленный в [`Dockerfile`](./Dockerfile), отличается от стандартного порта Express. Сначала определить и проверить желаемую схему деплоя, затем исправлять контейнеры.
- До выхода в интернет проверить секреты, тестовый доступ администратора, настройки JWT и резервирование данных. Не записывать пароли, токены или содержимое `server/data.json` в документацию и запросы к ИИ.
- [`README.md`](./README.md) полезен как исторический контекст, но команды и функции сверять с кодом: он содержит устаревшие/расходящиеся утверждения.

Карта API — в [`API-Reference.md`](./API-Reference.md), карта разделов — в [`Project-Structure.md`](./Project-Structure.md).
